# Levantamento de Requisitos — Sistema de Rede de Cinemas

## Requisitos Funcionais

### RF01 — Cadastro de Cinemas
O sistema deve permitir o cadastro de cinemas contendo:
- Nome do cinema;
- Cidade e estado;
- Endereço completo;
- Capacidade total de público.

### RF02 — Cadastro de Filmes
O sistema deve permitir o cadastro de filmes contendo:
- Título;
- Duração;
- Gênero;
- Classificação indicativa;
- Diretor;
- Elenco principal.

### RF03 — Controle de Filmes em Cartaz
O sistema deve permitir associar filmes aos cinemas onde estarão em exibição.

### RF04 — Cadastro de Sessões
O sistema deve permitir cadastrar sessões de filmes informando:
- Filme exibido;
- Cinema;
- Data;
- Horário de início;
- Sala;
- Quantidade de ingressos disponíveis
- Registro de Público.

### RF05 — Consulta de Informações dos Filmes
O sistema deve permitir consultar:
- Gênero do filme;
- Diretor;
- Elenco;
- Duração;
- Cinemas onde está em cartaz.

### RF06 — Relatórios de Público
O sistema deve permitir visualizar:
- Público por sessão;
- Público total por filme;
- Público total por cinema.
